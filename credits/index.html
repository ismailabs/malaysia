Behind the images.

The photographers, sources and choices behind Between Places.

An independent view.

Between Places is an independent editorial and interface project by Ismail Studio. It is not affiliated with tourism authorities or the businesses pictured. Photographs are credited to their original creators; they are not presented as photographs made by the studio.

The essays draw factual context from Tourism Malaysia, UNESCO, George Town World Heritage Incorporated and Sabah Parks. Each portrait links its sources. This project does not sell travel, take bookings or claim to document a firsthand reporting trip.

Privacy & measurement.

This release loads no optional analytics service and sets no analytics cookies. Following a studio link works as an ordinary link, including with JavaScript disabled.

With JavaScript enabled, a studio click emits a local browser event containing only the link placement, the page path and the destination host. It is not stored or transmitted by this site. Query strings, names, email addresses and other personal data are excluded.

GA4 collection is not active. Connecting a future analytics service requires a real property, an appropriate consent implementation and verified collection before this statement changes.
