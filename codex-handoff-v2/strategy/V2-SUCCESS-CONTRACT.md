# What V2 must accomplish (plain language and observable result)

## Problem
V1 significantly expanded static SEO structure and infrastructure, yet visually remained a familiar editorial photography layout and even simplified a few GSAP sequences. User's success condition is NOT more code, more sections, or another self-rating. It is **a different, memorable interactive visual experience** recognizable as Malaysia.

## Nonnegotiable output
- Live Cloudflare website as the same canonical hostname.
- Dramatic opening geography→destinations, creative scroll gallery, authored studio finale, unique hero/interaction for 4 destinations.
- Deliberately changing dark→light/mood palette, striking visual and type composition, new source-backed authentic media or wholly original non-deceptive procedural art.
- Functional HTML document for each destination and accessible no-motion/mobile paths.
- Both prototypes tested and compared in browser before implementation; evidence, not paper directions.
- Honest baseline and post-change lighthouse/a11y/screenshots, security and SEO checks.

## Anti-regression red lines
- V2 no longer looks like beige/stone quiet uneven photo prints plus small type across all sections.
- New hero cannot be merely a static map/image or a parallax image in a grid.
- Gallery cannot be existing ordinary native cards with generic fade-ins; must have at least one remarkable choreographed spatial transition.
- Finale cannot be a stock footer + CTA. Narrative reveal demonstrates Ismail Studio craft while preserving clear link.
- Four destination pages cannot share an identical static hero with only switched image and text.
- Do not inflate outcomes through artificial screenshot differences (e.g. recolor only) or self-awarded high scores.

## Decision autonomy
Codex chooses exact visuals and implementation; user is not required to select among prototypes. Record *why* each direction wins/loses. If no prototype meets the creative mandate, revise it before proceeding. Do not spend all usage repeatedly theorizing concepts with no browser implementation.
