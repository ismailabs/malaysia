## Mandatory gates (all need real evidence)
1. **Two different prototypes**: actual `index.html` each, locally served and browser-interacted with; Concept A and B first folds and transition waypoints captured at desktop/mobile, with reviewed console/focus/reduced motion.
2. **Actual selection**: decision log with screenshots/video, strengths/weaknesses, 2+ concept differences and justification against user goals; no self-performed meaningless A/B preference claims.
3. **Geographic opening**: correctly located both main Malaysia landmasses, an actual visible scroll transformation to photographic world, viable no-motion still; not a static SVG or generic photo animation.
4. **Immersive gallery**: visibly and interactively distinct composition across all four destinations; clear links, correct keyboard/touch operation, no scroll hijack.
5. **Cinematic finale**: major visual reveal of Ismail Studio, prominent studio link and real working navigation; not a footer text fade.
6. **Four distinct destination acts**: bespoke hero compositions and at least one unique working interaction per route; no single identical template with different photo/name.
7. **Matched before/after visual captures**: desktop 1440×900 and mobile 390×844 at first fold, major scene(s), final studio, plus sample destination; create side-by-side review board, inspect captures manually or with available built-in image viewers.
8. **Substantive difference statement**: identify concrete before→after changes in topology/layout, contrast/atmosphere, type hierarchy, unique procedural assets, motion mechanics, finale and per-route experience; not counts of changed lines/animations or inflated numerical creativity rating.
9. **Iteration**: record >=2 evidence-driven corrective rounds after first full implementation with problem, changed code and resulting screenshot/test difference. Fix issues; don't equate repetitive polishing with substance.
10. **Functional release baseline**: visual claims do not excuse broken keyboard/reduced motion/mobile, factual mistakes or deployment failures.

## Definition of a failed creative result
- Default photographic editorial grid remains unmistakably similar to V1; the typography, color or image crops are the primary changes.
- 'Geographic hero' only shows a map in the background and does not become a cinematic world.
- Gallery and finale are cosmetic CSS fades/scales with no spatial/narrative state change.
- The four route introductions are copies.
- Only still moodboards, generated source code or self-reported ratings are presented as visual evidence.
- No fresh or original procedural visual compositions; only old 7 photographs shuffled across section templates.

## Honest automation boundary
`check_visual_gate.py` checks existence/integrity of a defined evidence set, **not creative excellence**. Human/agent visual reasoning must review actual screenshots *and* motion recordings. Pixel differences are not an acceptable proof alone. A passing path or score is necessary at most, not sufficient for this creative gate.
