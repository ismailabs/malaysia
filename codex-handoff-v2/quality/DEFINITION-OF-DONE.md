# V2 definition of done — no substitute deliverables

## Gate A — creative (must pass before deploy)
- [ ] V1 visual baseline captured at matched desktop/mobile sizes **before site change**.
- [ ] Two distinct browser-working prototypes with authentic/map/procedural source rights and captured interactions.
- [ ] Autonomous decision compares both; selected concept justified and significantly different from V1.
- [ ] Three signature homepage scenes actually interact (map→places, immersive gallery, studio finale), with new visual language, original assets and strong choreography.
- [ ] Four static destination routes have distinct cinematic intro and route-specific interaction; shared cohesive design tokens.
- [ ] Visual gate review compares actual screenshots/videos with V1, includes >=2 substantive iteration cycles, no generic fade-only replacements.

## Gate B — function, SEO and safety
- [ ] Native predictable scroll, nonblocking/skip/pause opening, reduced-motion/no-JS, keyboard/touch and accessible destination/studio links all work.
- [ ] All public routes SEO crawlable with accurate Malaysian facts, individual metadata/canonicals/schema where appropriate, robots/sitemap, 404 and credits.
- [ ] No fake documentary image, fabricated travel facts, unattributed/unauthorized real photos, paid assets or leaked secrets.
- [ ] Browser/axe/a11y scripts pass defined core journeys, serious/critical problems fixed, unavailable devices/browsers explicitly disclosed.
- [ ] Mobile quality/perf measured honestly vs V1; trade-offs explained and poor experience mitigated.
- [ ] Studio CTA destinations actually work; GA4 verified only if truly wired with credentials + consent, otherwise named pending.

## Gate C — release and integrity
- [ ] Safe implementation branch/commits, rollback recovery and no dirty secrets included.
- [ ] Static `dist/` contains ONLY public allowlisted assets, with correct route files and no agent/package/docs/test tooling or `.env`.
- [ ] Noindex staging URL deployed/tested; production custom hostname changes only when staged build passes.
- [ ] `https://malaysia.ismailstudio.my/` verified by live HTTPS requests and real-browser scene/CTA checks; exact Cloudflare version and route status recorded.
- [ ] Legacy Vercel 308 redirect still works for homepage, nested route and encoded query; do not disturb working configuration.
- [ ] Final delivery report gives live URL, Git SHA, changes, visual comparisons, screenshots/motion evidence, browser tests, accessibility/performance observations, missing checks, future items and rollback procedure.

## Blocker policy
If actual account rights, network, platform confirmations, unavailable code runtime or licensed images prevent a hard gate, record exact evidence and user action needed. Continue safe useful work; do **not** claim fully done or fake evidence. Unavailable optional GA4 and aspirational subjective award quality do not alone block release when core experience and safety checks pass.
