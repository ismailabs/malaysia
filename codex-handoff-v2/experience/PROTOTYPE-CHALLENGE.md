# Two functioning competing prototypes — mandatory and bounded

## The purpose
Spend a small, deliberate portion of effort demonstrating two unmistakably different experimental concepts in the browser, not creating two entire websites. Codex chooses winner autonomously; no routine user approval.

## Both prototypes MUST have
- A real HTML entry served from a local HTTP server, no fake/static still mockup passed off as a working prototype.
- Correct Peninsular Malaysia + Malaysian Borneo geography, visible location targets and functional interaction to at least one real destination.
- A working opening + **one signature transition** that changes the page composition significantly; GSAP controls it and reduced-motion/mobile alternatives exist.
- A clear visual identity, authentic photographic source for any real view, original procedure/SVG assets, and an indicative studio CTA.
- Browser captures at 1440×900 and 390×844; 3 waypoints each, console errors, native scroll, reduced motion, source/credits/known limits.
- Reasonable assets/implementation, no Three.js/WebGL, paid API or backend. Disposable code lives in `output/v2/prototypes/a/` and `/b/`, never accidentally deployed.

## Concept A: Atlas Into Cinema
Map edges/pins and routes are physical staging. Camera-like travel follows real spatial relationships: begin from Peninsula + Borneo, focus on KL/Penang/Langkawi, traverse maritime break to Sabah, map paths become photo mattes, labels reorganize to a destination composition. Use real geographic shapes from appropriately licensed vector/map data (or provenance-documented hand simplified outline). Art direction: dark relief/ink, precise routes, big geographic lighting and decisive cuts.

## Concept B: Surreal Landscape Passage
Accurate Malaysian map first, then its shapes dissolve into atmospheres and layered authentic photographic planes; transitions create portal-like island, street and mountain worlds. Art direction: cinematic environmental color transformation, depth layering, reveal masks, large typographic passages. The landscape *presentation* can be surreal; **never pretend invented geography or photography is real**.

## Keep the prototypes different
A should communicate location/navigation as the main visual logic. B should communicate atmosphere/transformation as main logic. Not 'same exact map with altered gradients and timing'. Require two screenshots with different first-second composition, different motion mechanics, and different ending composition.

## Winner evaluation
For each: strengths, weaknesses, visual novelty vs current V1, legibility, Malaysian place truth, perceived drama, interaction accessibility, mobile quality, source/licensing risks, potential CTA transition, estimated engineering complexity. Include linked screenshot/video evidence and actual console/performance observations; don't invent weighting to guarantee winner. If both fail to be memorable, revise both minimally before committing.

## Decisions log format
Create `output/v2/prototypes/DECISION.md` with concept names, production test URLs, commit/time, capture names, 8 comparison dimensions, explicit winner and 3 differences from V1 at a glance. Timebox comparison; then retire the loser rather than mixing every effect into one incoherent design.
